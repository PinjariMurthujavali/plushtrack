How to get a free API key
  1. Open console.cloud.google.com and create a project.
  2. Go to APIs & Services → Library, search YouTube Data API v3, click Enable.
  3. Go to Credentials → Create credentials → API key, copy it and paste above.
  4. (Recommended) Restrict the key to YouTube Data API v3 and to your website domain.

Channel category ki saripoye video generate chesi YouTube ki upload chestundi.

📖 Process: edi enduku, ekkada nundi?
  1. YouTube API key + Channel link (paina Setup lo): mee channel niche/category telusukovadaniki.
  2. OAuth Client ID (console.cloud.google.com → Credentials → OAuth client → Web). Authorized origin lo mee site URL pettali. Upload permission kosam, YouTube Data API v3 enable cheyyali.
  3. Video AI API key (aistudio.google.com/apikey). Video generate cheyyadaniki. Model name field lo mee model (Veo / Omni) ID pettandi.
  4. Daily credits: mee plan limit enter cheyyandi (e.g. 50). Reset time ayyaka Auto mode malli start avthundi.
  5. Manual = nuvvu prompt isthav, preview chusi upload. Auto = category batti idea → generate → upload, daily budget varaku.

⚠️ Auto mode browser tab open lo unnappude run avthundi (server ledu). Unverified API projects lo uploads Private ga veltayi.
